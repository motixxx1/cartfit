# CartFit Chrome Extension

טוען סל שנבנה באפליקציה ישירות לעגלה באתר הרשת.

1. `chrome://extensions` → Developer mode → **Load unpacked** → בחר את התיקייה הזו.
2. באפליקציה: לחץ "שתף סל" והעתק את הקוד (למשל `AC5DRK`).
3. היכנס לאתר הרשת, פתח את התוסף, הדבק את הקוד ולחץ "טען את הסל לעגלה".

התוסף מפעיל את תיבת החיפוש של האתר עצמו ולוחץ על "הוסף לעגלה" לכל פריט —
אין API ציבורי להוספת ברקודים בעגלות של הרשתות בישראל. הסלקטורים לכל רשת
נמצאים ב-`content.js` וניתן לעדכן אותם בלי לגעת באפליקציה.
